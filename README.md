# RESONA

O RESONA é um projeto escolar que estou a desenvolver para a minha PAP, no curso de Técnico de Gestão e Programação de Sistemas Informáticos.

A ideia é criar um site de música inspirado no Letterboxd, mas em vez de filmes, os utilizadores podem avaliar álbuns musicais.

## Funcionalidades

- Adicionar álbuns e artistas
- Avaliar álbuns de 1 a 5 estrelas
- Escrever opiniões sobre os álbuns
- Consultar os álbuns adicionados
- Apagar álbuns da lista

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Objetivo

O objetivo é desenvolver um site simples onde seja possível guardar e avaliar álbuns musicais.

O projeto ainda está numa fase inicial e vou acrescentar novas funcionalidades ao longo do desenvolvimento.
